# Simple Interest Calculator

A simple tool to calculate simple interest.

## Formula
I = P × R × T

Where:
- **P** = Principal amount
- **R** = Annual interest rate (as a decimal)
- **T** = Time in years

## Example
If P = 1000, R = 5%, T = 2 years:
I = 1000 × 0.05 × 2 = **100**

## Technologies
- Bash / Python / JavaScript (whichever you used)

## Usage
Run the script and enter the principal, rate, and time.
